# Hope-Merge-Frontend

Браузерный клиент многопользовательской виртуальной галереи, сделанный командой Hope&Merge на хакатоне. Three.js + TypeScript + Vite, интерфейс на HTML поверх canvas.

> Проект завершён, репозиторий в архиве.

## Связанные репозитории

- **Бэкенд (Go):** https://github.com/MrDuckVC/hakaton-gallery-HopeAndMerge
- **Контракт API:** [api.md](api.md), расширение Sunday — [api-sunday.md](api-sunday.md)
- **План работ:** [frontend-plan.md](frontend-plan.md)

## Возможности

- Трёхмерный зал галереи, построенный из описания комнаты, переходы между залами через двери.
- Мультиплеер: игроки видят друг друга, общий чат, один WebSocket `/api/v1/ws`.
- ИИ-гиды: диалог с ответом потоком, просьбы вроде «Изменить экспозицию», жест гида.
- Посетители (NPC): смотрят картины, подходят к гиду, выходят в дверь и возвращаются.
- Лампа: взять, включить, повернуть и наклонить; видимый луч и подсветка картин.
- Фотоаппарат и альбом: съёмка кадра, загрузка на сервер, отправка фото в чат.
- Админ-панель: настройка гида и зала, таблица клиентов с FPS и ping.
- Бюджет кеша 10%: загружен ровно один зал, при переходе старый зал выгружается целиком.
- Переподключение по кодам закрытия WebSocket с экспоненциальной паузой.

## Управление

| Клавиша | Действие |
|---|---|
| E | взять / поставить лампу |
| Q | включить / выключить лампу |
| Z / X | повернуть лампу |
| C / V | наклонить головку лампы |
| B | альбом |
| Enter | чат |

## Запуск

Нужен [bun](https://bun.sh) 1.4 или новее.

1. Установить зависимости: `bun install`
2. Запустить dev-сервер: `bun run dev` (`http://127.0.0.1:5173`; именно `127.0.0.1`, не `localhost`)
3. Открыть страницу в браузере.

## Моки или реальный бэкенд

Переключатель `VITE_USE_MOCK` в `.env.development` (локально переопределяется в `.env.development.local`, после смены нужно перезапустить Vite):

- `true` (по умолчанию) — запросы к `/api/v1` и WebSocket обслуживает мок из `src/network/mock/`, бэкенд не нужен.
- `false` — запросы идут через прокси Vite на бэкенд `http://127.0.0.1:8080`. Бэкенд нужно запустить с `ALLOWED_ORIGINS=http://127.0.0.1:5173` и `COOKIE_SECURE=false`, см. [репозиторий бэкенда](https://github.com/MrDuckVC/hakaton-gallery-HopeAndMerge).

## Команды

- `bun run dev` — dev-сервер.
- `bun test` — тесты.
- `bunx tsc --noEmit` — проверка типов.
- `bun run build` — проверка типов и production-сборка в `dist/` (моки в неё не попадают).
- `bun run preview` — локальный просмотр собранной версии.

## Структура

- `src/game.ts` — точка сборки: рендер, цикл кадра, соединение, связь сцены, сети и UI.
- `src/network/` — контракт, HTTP/WS-клиент, переподключение, мок сервера.
- `src/world/`, `src/scene/`, `src/players/`, `src/npc/`, `src/lamp/` — мир, зал, игроки, посетители, лампа.
- `src/photo/`, `src/album/` — съёмка и альбом.
- `src/admin/`, `src/ui/` — админка и HTML-интерфейс.
- `tests/` — тесты на bun:test.
